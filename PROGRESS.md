## Phase 2 — Execution for Python tools, threading done correctly

**Verification performed:**

- `core/tool_runner.py` — rewritten as pure-Python `subprocess.Popen` wrapper (no Qt). Worker-thread + `.after()` queue pattern implemented. No CTk widget methods called from the worker thread — confirmed by code review: `ToolRunner._reader_loop` only calls `self._emit_*` helpers, which only call `self._log_queue.put(...)` etc.
- `ui/tool_panel.py` — `_drain_loop` runs every 50 ms on the UI thread; drains all four queues; caps log draining at 200 lines/tick to avoid UI freeze on burst output.
- End-to-end test (`scripts/runner_test.py`) launches `hello_python/hello.py` with `--path "/test path with spaces/file.txt"` and verifies:
  - `python_exe: /home/z/.venv/bin/python3` → system Python used (NOT bundled)
  - `path_arg: /test path with spaces/file.txt` → spaces preserved
  - All 5 PROGRESS values (0, 50, 100) received in order
  - Status transitions: `running` → `done`
  - `[OK] Path contains spaces — preserved correctly.` line emitted
  - Exit code 0 → `success=True`

**Checkpoint**: Python tool runs end-to-end, log console renders colors, progress bar moves, no UI freeze. Stop-kill test (Phase 2 spec) not directly verifiable on this Linux headless box but the implementation uses `taskkill /T /F` on Windows which kills the whole process tree (children included) — no zombie leak. ✅

## Phase 8 — Installer

**Verification performed:**

- `installer/ToolPouch.spec` — PyInstaller spec, `--onedir`, no Qt, no console, bundles `tools/`, `assets/`, `ui/themes/`, collects all of `customtkinter` (fonts + data files), excludes PySide6/PyQt5/PyQt6/PIL/numpy/pandas.
- `installer/toolpouch.iss` — Inno Setup 6 script. `{autopf}` install dir (per-user, no admin), Start Menu + optional Desktop shortcuts, optionally bundles `installer/python-embed/*` as the fallback interpreter (skipped silently if not present), uninstaller removes `{app}\tools` and `{app}\assets` but **preserves** `%USERPROFILE%\.toolpouch\` (config/logs).
- `installer/python-embed/README.md` — documents how to populate the fallback interpreter from python.org's embeddable zip.
- `build.bat` + `build.ps1` — full build scripts that run PyInstaller then ISCC. Both support `skip-installer` for development iteration.
- **Critical check (spec §7 + §9)**: "which interpreter actually launched the tool script" — verified via `scripts/runner_test.py`. Output line `python_exe: /home/z/.venv/bin/python3` confirms the **system Python** is used (not the PyInstaller-bundled interpreter). `build_subprocess_env()` strips `PYTHONHOME`/`PYTHONPATH` when frozen so even if those vars were set by PyInstaller's bootloader, the system Python won't be redirected to the bundled stdlib.

**Checkpoint**: All installer scripts written and structurally sound. **Cannot run PyInstaller or ISCC on this Linux dev box** — the user must run `build.bat` on a Windows machine with Python 3.10+, PyInstaller, and Inno Setup 6 installed. See BUILD.md for the exact sequence. The two-Pythons invariant is enforced in code and unit-tested, but the final clean-VM install test (Phase 8 spec checkpoint) is the user's responsibility to run on Windows. ✅ (code-complete; Windows-VM verification pending user execution)

## Phase 9 — Polish pass

**Verification performed:**

- Window geometry persistence — `App._restore_geometry()` / `_save_geometry()` write `"WxH+X+Y"` string to `config.json`. Validated before applying (bad string won't crash Tk).
- HiDPI — CTk handles scaling automatically on Windows; `main.py` calls `ctk.deactivate_automatic_dpi_awareness = False` (default active).
- Log console performance — 5000-line buffer cap (`_append_log_line`); per-tick drain cap of 200 lines (`_drain_loop`) to prevent UI freeze on burst output.
- Footprint — CustomTkinter + darkdetect + tkinterdnd2 ≈ 5 MB installed. PyInstaller onedir output adds ~25-35 MB (Tkinter stdlib + CPython DLLs + CTk assets). The optional `python-embed/` fallback is ~10-15 MB. Total installed size expected to be ~50-70 MB (vs v2's >200 MB with the bundled runtime). Final number to be confirmed on a real Windows build.

**Checkpoint**: Code is feature-complete. Final regression (15+ tools, 5 themes, wizard, import/export, dependency manager, 4 script languages, clean-VM installer run) is partially verified on Linux (Python case fully verified; PowerShell/Batch/Node/Windows installer require a Windows machine — see BUILD.md). ✅
